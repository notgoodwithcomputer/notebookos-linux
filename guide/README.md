# Notebook OS Guide

Documentation for Notebook OS 1.0.

This guide describes what Notebook OS does: the screens it presents, the
controls on those screens, the result of using each control, and where the
resulting data is stored. It does not cover source code or build procedure.
Those are documented in `docs/`, `ROADMAP.md`, and the modules themselves.

## Conventions used in this guide

- Menu paths are written as `File > Save As`.
- Keyboard shortcuts are written as `Ctrl+S`.
- File paths are written from the user's home folder, for example
  `Documents/report.writer`.
- "The system" refers to Notebook OS as a whole; "the desktop" refers to the
  screen shown when no application is open.
